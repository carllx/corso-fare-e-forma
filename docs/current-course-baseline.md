## 二、课程定位与层级边界

### 1. 学校统一课程框架 `[VERIFIED]`
- **课程属性**：广州美术学院通识教育核心课，面向大一年级全体学生，第一学期开设。8 学分，128 学时，全周期 8 周，划分为四个连续递进阶段。
- **学年主题**：「有 · 无」（保罗·瓦莱里“无中生有”；《道德经》“埏埴以为器，当其无，有器之用”）。主题是贯穿全课的核心命题与精神锚点，而非束缚日常知识点的教条框套。
- **双轨组织**：
  - **大班讲座**：前 3 周完成 3 讲通识大课（900 座报告厅），负责为全校新生搭建通识认知框架与文明史/艺术史视野。
  - **小班实践**：由各学院结合本专业特点自主设计训练与作业；各阶段统一使用课程案例库；前两阶段由通识中心配发统一“教学工具包”。

### 2. 林昕小班实践教学边界 `[INFERRED]`
- **授课对象**：雕塑与公共艺术学院本科一年级学生。
- **核心定位**：**小班不重复大课的史论叙事，而是作为大课认知支点的工作室实践转化器（Studio Lab）**。大课讲“认知与机制”，小班发生“动作、材料、身体、空间与推演”。
- **双轨承接原则**：
  - 通识中心“教学工具包”作为阶段性成果交付、全校档案归档与教材素材提取的标准接口；
  - 学生的个人视觉手记（Visual Journal）、材料标本袋、偶发测绘图纸与现场试验记录，作为日常实践的原始发生现场；
  - 两者以“日常自由深挖、阶段整理摘要并入工具包”的方式并存，完全满足官方对过程性成果与教材素材的合规要求。

## 三、林昕小班核心教学取向 `[INFERRED]`

1. **实践优先**：坚持实践优先导向，以工作室实验、场地操作与实体推进为主体，不让漫长理论宣讲挤占小班核心时间；不硬性冻结固定的课堂时间配额或“规则发布后全额动手”的机械排期。
2. **材料、身体、空间与过程**：强调物质阻力、重力感知、身体尺度、现场情境与过程推演，鼓励通过具身体验与物理触觉展开工作，避免脱离材料与空间的空泛概念推演。
3. **从直接经验进入问题**：问题意识源自学生在身体操作、材料交互、日常空间或真实经验中的直接感知与遭遇；不限定问题必须仅来自物理缺陷或受阻，亦不从先验哲学观念空推。
4. **保留失败、变化和过程证据**：造物生成（Morphogenesis）中的形变、妥协、试错样本与演变痕迹构成核心过程证据；鼓励真实探索与过程呈现。
5. **艺术家案例定位**：主要服务于实践推进和学生的知识兴趣；必要时可以提供简要的历史、观念与语境，但不让史论讲授占据小班主体时间；不写成“只允许提取动作指令”。

## 四、四阶段小班实践映射与成果要求

```
Part 1「原点」 (W1 / 16学时)
  │  ├── 核心变化：脱除预设造型惯性，直面未经分化的材料物性与身体感知
  │  └── 交付证据：《感知记录》（官方工具包承接 ＋ 原始触觉/材料手记）
  ▼
Part 2「0 → 1」 (W2-3 / 32学时)
  │  ├── 核心变化：从散漫感官感受中提炼出聚焦的造物问题意识
  │  └── 交付证据：呈现《对造物最原初的感受》（候选方法如问题梳理、粗模记录等）
  ▼
Part 3「1 → N」 (W4-6 / 48学时)
  │  ├── 核心变化：单一问题驱动，遵守实验纪律，推演可比较的变体序列
  │  └── 交付证据：造型语法专题练习（多件可比较实体变体序列，追踪变化与实验影响；候选方法如小型复数、构造节点等）
  ▼
Part 4「N → 我」 (W7-8 / 32学时)
     ├── 核心变化：从形式实验收敛到个人创作立场，在实体造物中回答「有·无」
     └── 交付证据：实体造物作品 ＋ 图文过程记录（Claim-Evidence 阐述「有·无」）
```

### Part 1「原点」：整体认知、直接造物 (1 周 / 16 学时)
- **学生核心变化 `[INFERRED]`**：降低对预设造型与既定控制套路的依赖，重回未经分化的感知。建立：我的感知 → 我的世界 → 我与世界的关系。
- **大课支点承接 `[VERIFIED: 官方 p.16]`**：大课第 1 讲提供“史前文明、原始艺术、纯真之眼、儿童艺术”等认知视野；小班直接落实为徒手与材料的直面接触。
- **必须留下的成果 `[VERIFIED: 官方 p.21]`**：教学工具包 ＋ 自设训练：完成一份《感知记录》。留存触觉、听觉、重量感知笔记，避免过早陷入设计草图模式。

### Part 2「0→1」：感知认知、问题意识 (2 周 / 32 学时)
- **学生核心变化 `[INFERRED]`**：从“被动接受材料感觉”转向“主动提炼造物问题意识”。察觉身体在空间中的受阻、行为的缺失或材料交互的张力，将其收敛为一个具体且可解的微命题。
- **大课支点承接 `[VERIFIED: 官方 p.16]`**：承接大课关于“无中生有（Ex-formation）、观察与视觉认知”的讨论。
- **必须留下的成果 `[VERIFIED: 官方 p.21]`**：教学工具包 ＋ 自设训练：呈现《对造物最原初的感受》。
  - *候选方法 `[Candidate Method]`*：“结构化问题清单”、“1:1 身体尺度/空间占位的粗模试验记录”等作为可选用探索方法，不作为当前基线的硬性交付要求。

### Part 3「1→N」：规律语法、形式创造 (3 周 / 48 学时)
- **学生核心变化 `[INFERRED]`**：克服单件雕塑直奔成品的创作惯性，学会控制变量与遵守实验纪律。围绕 Part 2 确立的单一问题，生成多个可横向比较的实体变体。
- **控制机制决断 `[INFERRED / Q2 Approved]`**：
  - **统一实验纪律与过程规则，不统一材料**：保留雕塑专业对多样材料（泥、木、金属、现成品、废弃物、软材质）的直觉与优势；
  - **追踪变化因果**：要求能追踪每轮实验改变了什么、产生了什么结果、以及哪些失败反向改变了后续判断；
  - 鼓励单变量对比尝试，但不硬化为教条。
- **大课支点承接 `[VERIFIED: 官方 p.16]`**：大课第 2 讲提供“营造法式、材分制、模数制、晋祠、三位一体”等秩序与法度认知；小班落实为模数、构造与形式秩序的推演。
- **必须留下的成果 `[VERIFIED: 官方 p.22]`**：造型语法专题练习。围绕同一问题产生多个可比较实体变体，并能追踪每轮改变、结果和失败对后续判断的影响。
  - *候选方法 `[Candidate Method]`*：Small Multiples（小型复数矩阵排列）、构造节点（Joint）无胶装配、固定样本数量等均标记为候选方法，供教学设计选用，不作为已冻结的硬性课程要求。

### Part 4「N→我」：风格范式、反观自身 (2 周 / 32 学时)
- **学生核心变化 `[INFERRED]`**：从多路径的形式实验中做出取舍，确立个人的创作坐标与形式语言，完成实体造物并能自洽解释其存在的理由。
- **大课支点承接 `[VERIFIED: 官方 p.16]`**：大课第 3 讲提供“现代性演变、风格范式破格、创造主体能动性”；小班落实为作品与现场环境、观众行为及地面/空间关系的建立。
- **必须留下的成果 `[VERIFIED: 官方 p.22]`**：一件实体造物作品 ＋ 图文过程记录（结课作业，作品阐述中说明自己的“无”与“有”）。

## 六、评价机制与结课验证标准

### 1. 「有 · 无」主题评价核心：Claim → Process Evidence → Final Work 的可追溯关系 `[INFERRED / Q3 Approved]`
- **评价原则**：允许学生从材料、空间、动作、规则、时间、关系、身体介入、缺失、观众行为等任意维度切入回应主题。
- **可追溯关系**：坚决杜绝空洞拼贴哲学辞藻作为万能掩护；强调创作主张（Claim）、推演过程证据（Process Evidence）与最终实体作品（Final Work）之间的因果演进与可追溯关系。
- **非机械对应**：**不要求每个不可见机制都必须有一一对应的物理对象**，重点审视：
  1. **始之无（从何而始）**：所关注的动因、问题、感知或空间/行为情境，在前期手记与试验记录中可追溯其起源；
  2. **成之有（何以成有）**：最终呈现的实体形式、材质与构造，能清晰追溯至具体规则演化与材料博弈的过程；
  3. **留之无（何处留无）**：作品为空间、时间、观众或未完成状态保留的不可见机制，与物理实体形成合理的场域或感知关联。

### 2. 过程证据与最终实体的共存机制 `[INFERRED / Q5 Approved]`
- **共存原则**：最终评价同时审视“实体作品”与“过程证据”，最终作品不脱离前期推演过程单独受评。
- **证据形态**：试错样本、变体记录、视觉手记、阶段工具包等均构成不可或缺的过程证据。
- **弹性质押**：不提前冻结具体的百分比权重，亦不硬性规定统一的展台格式，留待后续阶段教学合同结合实际情况确定。

## 七、仍然保持 OPEN 的议题 `[OPEN]`

以下议题确认未在当前基线中锁定，留待后续阶段深化：

1. **学生既有训练习惯及其实际影响的开课观察**：
   - 大一新生入学的既有造型习惯、工具熟练度与惯性心理，对四阶段推进节奏的真实影响，需要在开课初期通过现场操作持续观察并灵活调节。
2. **Practice Paradigms（实践范式与实验设计）的具体规则库**：
   - 指令式（Instruction-based）、规则式（Rule-based）、限制式（Constraint-based）、偶然性（Chance）、身体行动（Bodily Action）、协作（Collaboration）等实践范式，如何在 Part 1～3 的具体课堂任务中转化为可操作的工作机制。
3. **现当代艺术案例集合**：
   - 梳理并筛选能够有效服务小班实践推进、激发知识兴趣并兼顾简要历史/语境的现当代艺术案例集合；不冻结具体案例数量，视教学需要动态配置。
4. **Visual Journal / 感知记录范例与实操指引**：
   - 补充一套向大一学生直观示范的优秀《视觉手记 / 感知记录》范例与记录维度参考；
   - 探索中国传统营造秩序（如材分制/模数思维）向实体模型推演转化的简易教学方法。
5. **Assessment / 结课展陈细则（Assessment Rubric）**：
   - 结合班级实际进度与场地条件，制定出具体的展示形式与评价细则，不提前冻结百分比或硬化展陈规格。
