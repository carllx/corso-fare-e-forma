## 一、双核心驱动模型 (Dual-Core Practice Principles)

在雕塑与公共艺术学院小班的实践教学中，九类候选机制并非彼此割裂的孤立动作，而是以**一对底层的“主客体博弈”双核心**为基础展开的。双核心的组合不是一种固定的课堂练习套路，而是用于生成各阶段具体实验任务的课程设计原则。

```
                  ┌────────────────────────────────────────┐
                  │      Bounded Action (有界行动)         │
                  │   [主体侧] 通过意识性规约限定行动空间     │
                  │    使行动能够 开始、持续、比较 与 修正    │
                  └───────────────────┬────────────────────┘
                                      │
                         动态博弈 / 因果反馈 (Action-Feedback Loop)
                                      │
                  ┌───────────────────┴────────────────────┐
                  │    Material-Responsive (物性响应)      │
                  │   [客体侧] 让材料、重力、阻抗与形变      │
                  │    提供真实反馈，并反向改变后续判断       │
                  └────────────────────────────────────────┘
```

1. **Bounded Action（有界行动 / 主体侧控制纪律）**：
   - **定义**：由 Constraint-based 提炼出的课程层上位机制，但不等同于塞拉（Richard Serra）“动词清单”这一特定历史案例。
   - **课程职责**：通过有意识地缩小行动空间、施加边界限制，降低“因行动选择过多而难以启动或缺乏聚焦”的潜在教学风险，让学生的实践能够明确开始、稳定持续、横向比较并及时修正。
2. **Material-Responsive（物性响应 / 客体侧物质真相）**：
   - **定义**：停止对材料强加外在抽象造型，将造型推进的依据建立在物质自身的自生属性之上。
   - **课程职责**：让材料、重力、物理阻抗与自发形变在现场提供即时、不可撤销的真实力学反馈，并允许这些物理反馈反向干预、修正创作者的后续判断，降低“脱离真实物理条件进行虚空造型”的潜在教学风险。

## 二、实践机制选择矩阵 (Paradigm Selection Matrix)

本矩阵将九类候选实践机制（Project Taxonomy）在小班四阶段中的职责归入四级分类：
- **A. Core / Recurring Mechanism**：跨阶段反复出现，构成本课程的核心实践语言。
- **B. Stage Mechanism**：对特定阶段具备关键支撑作用，不要求全课无差别贯穿。
- **C. Optional Tool**：根据课堂现场状态与学生探索需要，由教师有条件调用的辅助工具。
- **D. Hold / Not Adopted**：当前不进入课程执行层（当前分类保持为空，不强行剔除研究资产）。

| :--- | :--- | :--- | :--- | :--- | :--- |
| **7. Material-Responsive**<br>(物性响应) | **A. Core / Recurring** | **物理反馈与重力响应源** | **Part 1 → Part 4 全周期贯穿**<br>*(Part 4 执行方式待定)* | 降低过早脱离材料物理特性的空泛推演风险；避免无视重力与材质强度的形式拼贴。 | **严禁表面图式模仿**（如单纯悬挂毛毡或散落石块）；要求学生持续追踪材料在受力、支撑与连接时的真实物理平衡。 |

| **6. Bodily Action**<br>(具身行动与触觉重置) | **B. Stage Mechanism** | **触觉优先与具身阻抗感知** | **Primary home: Part 1 – 2**<br>*(Part 3–4 身体尺度作为意识存续，但不依赖行为动作)* | 降低对视觉形象惯性的过度依赖；防范问题意识悬浮于概念口号、缺乏身体受阻直感。 | **防范私人情绪宣泄**；身体介入必须与外部物理媒介或空间阻抗紧密咬合，留存可被客观评估的《感知记录》证据。 |
| **2. Rule-based**<br>(规则生成) | **B. Stage Mechanism** | **算法遍历与形式语法推演** | **Primary home: Part 3**<br>*(不绝对禁止在其他阶段出现)* | 降低变体推演阶段的任意拼凑风险；防范多方案之间缺乏逻辑关联或过早收敛单件。 | **严防纯纸面算术游戏**；规则推演必须落实在具体材料构件与咬合节点中，不能退化为脱离工艺特征的几何图示。 |
| **5. Repetition / Iteration**<br>(重复微变) | **B. Stage Mechanism** | **序列迭代与工艺容差沉淀** | **Primary home: Part 3**<br>*(不绝对禁止在其他阶段出现)* | 防范方案跳跃过快而无法形成深度沉淀；帮助适合序列研究的方向通过手工密度显现微差。 | **不冻结全员密集复数指标**；核心在于“可追踪因果的微差变体”，坚决拒绝导致思维麻木的无脑流水线劳动。 |

| **8. Collaboration**<br>(协作参与) | **C. Optional Tool** | **多主体力学互锁与尺度镜像** | **条件性短时调用**<br>*(如 Part 2 空间感知、Part 3 柔性张力节点)* | 借助他人身体作为力学支撑或感知参照，测量超出单人身体尺度的张力与空间界限。 | **防范责任分散与纯团建游戏**；当前不作为课程核心，结课作业评价边界留待后续 Stage 4 Contract 明确。 |
| **9. Site Intervention**<br>(场域介入) | **C. Optional Tool** | **原位微介入探测器** | **Current primary relevance: Part 2**<br>*(Part 4 保持为 Later Candidate)* | 引导学生在既有物理环境中寻找逼仄、受阻角落，从日常摩擦中提炼具体的空间问题意识。 | **严守不可逆建筑破坏与安全红线**；防范浮光掠影的拍照打卡，必须关注身体与构件在现场的真实受力与尺度。 |
| **—** | **D. Hold / Not Adopted** | **暂无** | — | — | 保持研究资产完整性，不强行为了填满四分类而剔除已有候选机制。 |

## 三、四阶段实践机制递进映射 (Four-Stage Mechanism Progression)

```
Part 1「原点」 (W1)
  │  ├── 核心挑战：脱除既定造型惯性，直面未经分化的材料物性与身体感知
  │  ├── 核心实践：Bounded Action (限制动词/材料范围) ＋ Material-Responsive (重力与自发形变)
  │  ├── 阶段机制：Bodily Action (触觉感知优先，抑制视觉审美定势)
  │  └── 备选工具：Instruction-based (极简行动卡启动)、Chance (重力落体阻断预设)
  ▼
Part 2「0 → 1」 (W2-3)
  │  ├── 核心挑战：从散漫感官中提炼出聚焦的造物问题意识
  │  ├── 核心实践：Bounded Action (单一问题锁定) ＋ Material-Responsive (材料物理博弈)
  │  ├── 阶段机制：Bodily Action (身体受阻感作为微命题入口)
  │  └── 备选工具：Site Intervention (原位空间死角微介入)、Collaboration (双人身体受力平衡短时探测)
  ▼
Part 3「1 → N」 (W4-6)
  │  ├── 核心挑战：避免过早收敛为单件成品，单一问题驱动，推演变体序列
  │  ├── 核心实践：Bounded Action (严守单变量控制纪律) ＋ Material-Responsive (材料容差与节点咬合)
  │  ├── 阶段机制：Rule-based (算法遍历推演) ＋ Repetition / Iteration (手工迭代沉淀微差)
  │  └── 备选工具：Chance (意外形变固化为新尺规)、Collaboration (柔性张力节点)
  ▼
Part 4「N → 我」 (W7-8)
     ├── 核心挑战：将实验范式收敛为个人创作判断，在实体造物中回答「有·无」
     ├── 核心实践：Bounded Action (个人语言聚焦) ＋ Material-Responsive (实体作品成立之物性)
     └── 机制决断递延：Site Intervention 作为 Later Candidate，具体执行方式留待 Stage 4 Contract 决断
```

## 四、未决边界与后续合同接口 (Open Boundaries)

1. **Stage 4 Contract 递延**：
   - Part 4 中实体作品与展览场地、地面、观众及空间虚实关系的具体处理，是否引入 Site Intervention 机制，待进入 Part 4 阶段教学合同（Stage 4 Contract）时正式判定。
2. **学生既有习惯的现场观察**：
   - 教学中是否需要密集调用 Optional Tools（如用 Instruction-based 破冰，或用 Chance 扰动僵化控制），取决于各班学生在第一周呈现出的具体状态，教师现场保留灵活调度权。
